# Understudy web

Vite + React + TypeScript + Tailwind + Framer Motion. Designed at 1920×1080 and scaled to fit.

```
bun install
bun run dev        # http://localhost:5180 (or next free port)
```

Keys: `1`–`4` screens · `Space` next beat · `R` reset · `?dev` dev hints.
Coach rehearsal (mock checker): `N` step done · `M` mistake.

Data lives behind `src/data/` (placeholders today, VastDB rows later; same shape).
Real thumbnails: set `thumbnail_url` to `/clips/<id>.jpg` and drop files in `public/clips/`.
